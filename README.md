# FitProgress 💪

Android-приложение для домашних тренировок (Kotlin + Jetpack Compose, Material 3).
Работает офлайн, без регистрации и сервера. Android 8.0+ (minSdk 26).

## Возможности
- 8 упражнений: отжимания, приседания, пресс, выпады, планка, прыжки «звезда», берпи, ягодичный мостик
- Настройка подходов и повторений/секунд для каждого упражнения
- Ручной счётчик +1 / −1, таймер планки, автоматический таймер отдыха (+15 с / пропуск)
- Персональный план: нагрузка растёт, когда выполнены все подходы, и снижается при результате < 60% цели
- Дни тренировок и дни отдыха, серия дней подряд
- Ежедневное уведомление в заданное время (по умолчанию 10:00), только в дни тренировок
- Главная с планом дня и кольцом прогресса; статистика за день / неделю / месяц; календарь и история
- Room (история, цели) + DataStore (настройки); каждый подход сохраняется сразу

## Сборка APK
Нужны: Android Studio Koala (2024.1) или новее, JDK 17 (встроен в Studio), Android SDK 34.

**Через Android Studio**
1. File → Open → папка `FitProgress`, дождаться Gradle Sync.
2. Подключить телефон (отладка по USB) или запустить эмулятор → Run ▶.
3. APK: Build → Build Bundle(s) / APK(s) → Build APK(s).
   Файл: `app/build/outputs/apk/debug/app-debug.apk` — его можно скопировать на телефон и установить.

**Через командную строку** (нужен установленный Gradle 8.7+, один раз создаёт wrapper)
```
gradle wrapper --gradle-version 8.7
./gradlew assembleDebug        # Windows: gradlew.bat assembleDebug
```

**Релизный APK с подписью**
```
keytool -genkey -v -keystore fitprogress.jks -keyalg RSA -keysize 2048 -validity 10000 -alias fit
```
Затем в Android Studio: Build → Generate Signed Bundle / APK → APK → выбрать keystore → release.
Храните `.jks` и пароли в надёжном месте (в `.gitignore` уже исключены).

### Ручной чек-лист
1. Первый запуск: разрешить уведомления; на главной план из 4 упражнений.
2. Отжимания: +1/−1, «Подход выполнен» → запускается отдых → таймер идёт и сам завершается сигналом.
3. Закрыть приложение посреди упражнения → открыть: завершённые подходы сохранены.
4. Планка: старт / пауза / досрочное завершение.
5. Завершить все подходы → ✅ на главной, на следующий день цель выше.
6. Настройки: сменить дни, подходы/повторения, время напоминания, паузу отдыха.
7. Уведомление: поставить время на 1–2 минуты вперёд (в день тренировки) — должно прийти.
8. Статистика (день/неделя/месяц) и календарь: цвета дней и список за выбранный день.
9. Перезагрузка телефона → напоминание продолжает приходить.
10. Режим «В самолёте»: всё работает.

## Известные ограничения MVP
- Напоминание ставится неточным будильником (`setAndAllowWhileIdle`): может прийти с задержкой в несколько минут. Для точного времени потребуется разрешение SCHEDULE_EXACT_ALARM.
- Текущее значение ручного счётчика внутри незавершённого подхода при убийстве процесса не сохраняется (завершённые подходы — сохраняются).
- Нет резервного копирования и экспорта истории.
